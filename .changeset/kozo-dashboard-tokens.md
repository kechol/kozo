The dashboard takes its colours, type, spacing and radii from one set of design tokens in a quieter palette, so every state has one colour wherever it shows: approval blue, work in progress yellow, a question orange, attention red, ready to merge green, merged violet and the other holds grey. Text is 14 px on a 4 px spacing scale, and fields have edges that stand out from the page.
