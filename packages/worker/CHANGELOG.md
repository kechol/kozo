## 0.1.0

### Minor Changes

- [`d32539e`](https://github.com/kechol/kozo/commit/d32539e0be94f8bf833b8b77e93467e8d665d7bb) Thanks [@kechol](https://github.com/kechol)! - The guard records why it refused a tool call as a message, shown in the factory's `locale` among a run's events; the agent still reads the refusal in English.

- [`efb3da7`](https://github.com/kechol/kozo/commit/efb3da79f532cfaef5655956e1bdfd37bbdfcb15) Thanks [@kechol](https://github.com/kechol)! - `runtime: cli` in `factory.yml` runs each agent session as `claude -p` instead of through the Agent SDK, with the same guard, sandbox, instructions and kozo tools. Judges and the verify session still run through the Agent SDK.

- [`6894842`](https://github.com/kechol/kozo/commit/6894842a4e91f4228d15adfa1cb5cedc62194e2c) Thanks [@kechol](https://github.com/kechol)! - The implement agent runs its gates with the `kozo_gates` tool instead of `kozo gates` in its shell. The worker runs them in the task's command sandbox, the one `kozod`'s own gates use, so browser tests and the deep gates run during the session. Stop-check accepts only a pass at the brief's level on the agent's last commit with nothing left uncommitted, and the guard refuses `kozo` in the agent's shell. The worker spec is version 2.

### Patch Changes

- [`76d27d1`](https://github.com/kechol/kozo/commit/76d27d1151fc070810cf02633d925a930aae77d3) Thanks [@kechol](https://github.com/kechol)! - With `runtime: cli`, a hook or tool call whose request or reply is larger than a socket takes at once now arrives whole instead of hanging or failing, text split mid-character is no longer garbled, and a Stop hook the worker cannot answer keeps the agent going instead of letting it stop unchecked. prepare's egress proxy closes a tunnel whose client left or whose token was revoked while it was still opening, stops reading from upstream once the client is gone, passes on everything upstream sent before it closed, and no longer reports a request without kozod's token. `kozo admin eval` stops its egress proxy even when a case throws, an eval teardown that cannot read the base documents no longer replaces the case's result, `kozo issue` opens the Issue with its intake label in one step so a failure leaves no Issue that a retry would open twice, and a kozod start that fails part way stops the proxy and the API server it started.

- [`12d3ec5`](https://github.com/kechol/kozo/commit/12d3ec5d8bebf7e8d77b3018ca6839338997c18c) Thanks [@kechol](https://github.com/kechol)! - The stop-check now sends an agent back when it hands in its answer before the gates passed on its last commit or before it noted a decision, in both runtimes; Claude Code used to end the session at the answer whatever the check said.

- [`643b9af`](https://github.com/kechol/kozo/commit/643b9af6ce307390523cc56c7e9651f77d13cbd1) Thanks [@kechol](https://github.com/kechol)! - Every command kozod runs for a task, prepare, services, gates, prove, codemods and the agent's `kozo_gates`, now ends within the Charter's `limits.max_minutes`: past it the command and everything it started get SIGTERM, then SIGKILL 10 seconds later, and the command fails with exit code 124 and a line saying it ran out of time. `kozo gates` run by hand has no limit.

- [`4e9cee8`](https://github.com/kechol/kozo/commit/4e9cee8b3e3a7832d027c0cd8a285bc549542917) Thanks [@kechol](https://github.com/kechol)! - An agent's shell can no longer read gh's and git's credentials under a custom `XDG_CONFIG_HOME`: kozod now gives the worker the credential paths it finds in its own environment, which the worker's environment lacks.

- [`dd51433`](https://github.com/kechol/kozo/commit/dd5143305e8539d8b0ea070b4fe96b881eb16c9c) Thanks [@kechol](https://github.com/kechol)! - On macOS, the commands kozod confines, prepare, the gates, prove and the agent's `kozo_gates` included, can no longer connect to kozod's API port; every other port of this machine stays reachable, so a test that starts its own server still works. On Linux the command's network already reaches only the worktree's ports.

- [`6da3c9d`](https://github.com/kechol/kozo/commit/6da3c9ddd631d177fa8bfc625451e62c9b2b2534) Thanks [@kechol](https://github.com/kechol)! - A failed agent session now says what kind of failure it was, an API failure, a spent limit, a finish without an answer or a crash, and only three API failures in a row pause the factory; three agents that answer without the structured result no longer pause it as an outage.

- [`aeb8667`](https://github.com/kechol/kozo/commit/aeb8667d57128730d913bcf40df37f33790346ba) Thanks [@kechol](https://github.com/kechol)! - The guard now treats a word with brace expansion, such as `{g..g}it` or `{gh,true}`, as built from an expansion, so a command name or git subcommand spelled that way is refused like one built from a variable; a lone brace, a group command and find's `{}` are unaffected.

- [`d4d67c6`](https://github.com/kechol/kozo/commit/d4d67c6ccf4ce4731f2727b9e5cf30960d568f27) Thanks [@kechol](https://github.com/kechol)! - The guard now refuses `git stash`, which the sandbox would fail after the call, and tells the agent to commit or keep editing instead; `git stash list` and `git stash show` stay allowed.
