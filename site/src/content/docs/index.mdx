kozo runs on your own machine. It takes requests from a local list or from GitHub Issues and
keeps producing verified diffs while nobody is watching. You write the policy, clear the inbox,
read each diff and merge it.

kozo is in early development and has no release yet. These pages describe the current `main`
branch.
