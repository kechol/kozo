kozo はあなたのマシンで動きます。依頼はローカルのリストか GitHub の Issue から受け取り、誰も見ていない間も、検証済みの差分を作り続けます。人がするのは、方針を書くこと、inbox を片付けること、差分を読んでマージすることです。

kozo は開発の初期段階で、まだリリースはありません。このサイトは、いまの `main` ブランチの内容を説明しています。
