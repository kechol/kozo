kozo は自分のマシンで動きます。ローカルのリストか GitHub の Issue から依頼を受け取り、誰も見ていない間も検証済みの差分を作り続けます。人は方針を書き、inbox を片付け、差分を読んでマージします。

kozo は開発の初期段階で、まだリリースはありません。このサイトは現在の `main` ブランチの内容を説明しています。
